# TEAM local

Team 'local' measured how block clusters combine in the shared MBO bubble engine. The work used about 900 3D runs: n = 12 for 14×2×5 slabs, n = 16 for the Task 4 contact scenes. It covered FID-0.15, FID-0.05, FINITE-4, CAGE-0.25, FREE and volume:false controls. Each run records three measures: labels (quantised at 1/n), D0 (the labels re-blurred with λ = 0, a purely local smooth field) and the renderer's own field D.

Headline: the bubble pressure λ (the volume constraint) is the only long-range carrier. Without it, a one-block add, remove, recolour or bridge changes labels only within 0–0.475 block of that block, and a probe 2 or more blocks away does not change at all. With it, the response reaches the whole cluster whenever λ changes. In this engine that response comes as whole sub-cell terraces (multiples of 1/12 block), placed where flat-face cells tie, rather than as a decaying tail. In three regimes it releases volume deficits the bases had stored (CAGE-0.25: the top face rises 0.25 at every distance).

The local near field has compact support: a FID-0.15 bump's skirt ends by 1.0 block, pits and inclusions by 0.25, the seam position by 0.5. Convex edges, inclusions and straight seams take the same shape in every cluster tested. A straight seam does not move at all in FID/FINITE (labels flat at n = 12 and 16); its groove is the renderer's blur of the unmoved blocks, which I give in closed form and which matches a discrete model to 4.75e-6 block. Concave features and thin attached features do depend on the whole cluster: under CAGE a 1×1 pillar's width falls 1.06 → 0.69 → 0.49 as the plate it stands on grows, and FID-0.05 drains an attached pillar completely. Superposition is exact only where λ stays fixed (FINITE-4, features 2 or more blocks apart).

At ambiguous contacts the smaller pair unites (FINITE-4, CAGE, FREE, and FID-0.05 for large size ratios). Equal sizes give no union with jitter 0 and with reversed block order, so there is no tie-break bias. Edge contacts with air always unite, corner-only contacts never do, and FID-0.15 never resolves an X. A local rule, "minority in a 4×4×3 window connects; ties none; air-X connects; corner never", matches the physics in 21/21 configurations for FINITE-4, 20/21 CAGE, 19/20 FREE, 19/21 FID-0.05 and 10/21 FID-0.15. It keeps the painted diagonal line continuous, as every regime except FID-0.15 does.

- [L17] (pattern, measured) A deterministic local rule reproduces the union outcome. At a lattice edge whose four surrounding blocks form an X: if the other diagonal pair is air, the solid pair connects. Otherwise count the two materials in a window 4×4 across the edge and 3 layers along it; the strictly smaller count connects, and a tie connects nothing. Corner-only contacts never connect. On the painted diagonal line the rule connects the line.
  numbers: Agreement with physics over 21 configurations (deterministic variants used where seeds split): FINITE-4 21/21; CAGE 20/21 (misses 'both' in 2v2); FREE 19/20 (misses 'both' in the 3D 2x2x2 checker); FID-0.05 19/21 (2v4 and 4v2: physics none); FID-0.15 10/21 (FID-0.15 never connects an X). slab-line: the rule says A connects, matching FID-0.05, FINITE-4, CAGE and FREE. The rule is Kopf–Lischinski's 'sparse pixels' heuristic for pixel art, cited from memory (inference).
  refuteBy: Build configurations where the window count and the true cluster sizes disagree, e.g. a thin line attached to a large blob outside the window. If the physics follows cluster size, the window rule fails.

## optimizations
- Run the bubble shape pass as a purely local rule with no global λ, so its reach is under 0.5 block and fits inside the mesher's existing 38³ region (apron 3). Pair it with an explicit thin-feature guard (the PLAN §7.4 kind), because without pressure the dynamics delete thin features.
