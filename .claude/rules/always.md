# General Rules

## Commits and Branches

Every session works on its own branch; `main` moves only by fast-forward.
Follow [session-branches.md](session-branches.md): branch before the first
edit, commit on the branch yourself (subject short and imperative, matching
`git log`; body only when the why isn't obvious), never commit on `main`, push
only when asked. Questions — including any prompt starting with "I want" — get
answers, not changes.
